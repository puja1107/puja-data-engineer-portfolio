# Puja Kumari | Data Engineering Portfolio

A static, responsive portfolio for Puja Kumari, focused on real hands-on experience in:

- Google Cloud data engineering
- BigQuery
- Dataflow / Apache Beam
- Cloud Composer / Airflow
- Python and SQL
- ETL / ELT and data modelling
- Telecom data platforms and CDR processing
- Qlik Sense / ODAG / QVD
- Data quality and production monitoring
- Terraform / GitLab CI/CD / IAM
- BigQuery performance and cost optimisation
- Superset POC

## Files

- `index.html` - portfolio content and structure
- `style.css` - responsive design
- `script.js` - navigation and small animations
- `assets/favicon.svg` - favicon

## GitHub Pages

1. Create a new public repository, for example `puja-portfolio`.
2. Upload all files while preserving the folder structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Before publishing

In `index.html`, replace:

- `YOUR_EMAIL@example.com` with the public email you want to use.
- The LinkedIn placeholder with your real LinkedIn profile URL.

Do not publish company-confidential data, internal screenshots, customer information, credentials, source code, tokens, private architecture, or proprietary numbers.

## Custom domain

If you later want a custom domain, add the domain in GitHub Pages settings and follow GitHub's DNS instructions.
